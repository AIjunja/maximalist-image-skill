# 과잉광고 이미지 생성 프롬프트

첨부 댓글의 프롬프트를 바로 쓸 수 있게 재구성한 템플릿이다. 대괄호는 이번 주제의 확인된 정보와 장면 요구로 채운다. 편집 대상이 있을 때만 원본 유지 문단을 사용한다.

```text
주제 [주제 및 행사처럼 과장할 사건]. 출력은 [비율] 포스터 한 장.
스타일 레퍼런스 [이미지별로 가져올 정보의 층·타이포그래피·장식 밀도]. 기존 시안을 다시 그리는 작업이라면 [유지할 주제·브랜드·필수 문구]를 이 스타일에 맞춰 새로 배치한다.
편집 대상이 있다면 원본 비율, 주요 레이아웃, 제품 외형과 핵심 정보, 사용자가 유지하라고 한 UI 요소의 역할을 보존하면서 아래 스타일로 재구성한다.

한 장의 결과물을 극단적으로 과장된 초고밀도 맥시멀리즘 광고 디자인으로 만들어라. 일본 파칭코 잭팟 연출, 돈키호테의 빽빽한 POP, 중국 모바일 MMORPG VIP 이벤트, 초호화 카지노 광고와 가챠 최고 등급 등장 연출을 한 화면에 섞는다. 평범한 정보를 인류 역사상 가장 위대한 사건을 기념하는 초대형 글로벌 이벤트의 광고처럼 떠받든다.

디자인은 초고채도, 초고대비, 금속 광택과 입체감을 끝까지 밀어붙인다. 거대한 황금색 3D 글씨와 무지갯빛 크롬 타이포그래피를 두꺼운 외곽선과 검은 받침으로 띄운다. 왕관, 월계관, 황금 날개, 다이아몬드, 크리스털, 트로피, 훈장, 리본 배너를 겹쳐 배치한다. 우주, 은하, 번개, 폭발, 무지갯빛 광선, 렌즈 플레어, 반짝이는 입자를 뒤에서 터뜨린다. 주제에 맞는 황금 사자, 백호, 여신, 로봇, 마스코트 등을 구석 소품으로 쓴다. 버튼형 띠, 계기판, 패널에는 화려한 금속 테두리와 네온 발광을 넣는다.

시선을 한곳에 모으는 주인공은 살리되 깨끗한 여백은 남기지 않는다. 화면 전체를 크고 작은 광고 문구, 설명, 체크리스트, 데이터, 순위나 마크가 실제로 있는 경우 그 정보, 강조 배너로 채운다. 같은 핵심을 크기와 형태가 다른 타이포그래피로 의도적으로 다시 보여준다. 틈에는 손글씨 감탄 문구, 하트, 별, 화살표, 보석, 작은 아이콘을 겹쳐 넣는다. 눈에 걸리는 긴 직선과 빈 구간을 배지와 팝업 스티커로 끊어라. 좌우를 다른 모양과 리듬으로 구성하며, 화면 가장자리까지 의미 있는 정보와 장식이 밀려와야 한다. 중앙에 그림과 제목만 크게 놓고 아래에 반듯한 카드 몇 장을 맞춘 형태로 정리하지 않는다.

중앙에는 [주인공·제품·상태]를 [장면]에 놓고, 메인 문구 [문구]와 보조 문구 [문구]를 읽히게 쌓는다.
왼쪽에는 [주제에 실제로 필요한 목록과 항목별 짧은 설명], 오른쪽에는 [수치·조건·관련 이슈·리본·스티커의 확정 문구], 하단에는 [아이콘 카드, 상태 게이지, 진행 단계 또는 타임라인의 확정 문구]를 넣는다.
가장자리에는 [핵심을 새로운 형태로 한두 번 더 강조하는 짧은 문구와 주제에 맞는 소품]을 넣는다.
실제 정보는 [확인된 사실, 수치, 단위와 시각]으로 제한한다. 확인되지 않은 사양, 순위, 수치, 배지 문구는 만들지 않는다. 밈으로 과장한 표현은 사실과 읽는 흐름이 겹치지 않게 표시한다.
구역별로 지정한 문구를 정확히 넣고 긴 정보는 짧은 줄로 나눈다. 작은 글자에는 어두운 받침, 밝은 글자, 얇고 선명한 외곽선을 적용한다. 광선은 간판 뒤와 모서리에서 터뜨린다. 지정 문구를 다 배치하고 남은 틈은 보석, 체크 표시, 광선, 별로 채운다. 플랫폼의 계정, 댓글, UI 테두리는 캔버스 밖으로 뺀다.
```
