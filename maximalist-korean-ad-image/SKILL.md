# 개킹받는 한국 광고 이미지

평범한 소재를 세상에서 제일 큰 출시, 복귀, 우승, 잭팟 행사처럼 연출한다. **소재는 한눈에 알아보고, 제목은 썸네일에서도 읽히고, 두 번째로 볼 때 주변에서 계속 뭔가 발견되는 그림**을 만든다.

## 요청 처리

- 사용자가 준 주제, 문구, 비율, 미감과 강도를 먼저 반영한다. 비율이 없으면 정사각형부터 잡는다. 주제와 필수 문구가 명확하면 바로 작업한다.
- “프롬프트만”이면 복사할 수 있는 이미지 프롬프트를 준다. 이미지 요청이거나 스킬 이름과 주제만 주어지면 사용 가능한 이미지 생성 도구로 한 장을 만든다. 도구를 쓸 수 없으면 이미지 상태를 알리고 바로 붙여넣을 수 있는 프롬프트를 준다.
- 사용자가 준 레퍼런스에서는 정보의 층, 글자 재질, 장식 밀도, 빛의 방향을 가져와 새 소재로 구성한다. 레퍼런스의 스크린샷 UI, 문구, 로고 배치, 레이아웃을 그대로 재현하지 않는다.

## 화면 구성

1. **주인공 하나와 거창한 사건 하나.** 중앙이나 상단 중앙에 인물·제품·사물을 크게 둔다. 월요일 출근은 ‘전격 개막’, 앱 업데이트는 ‘초대형 진화’, 평범한 기능의 복귀는 ‘전설의 귀환’처럼 잡는다. 웃음은 평범한 소재를 진지하고 호화롭게 다루는 데서 나온다.
2. **짧고 거대한 금속 한글.** 가장 중요한 문구를 금박 3D 글자, 두꺼운 외곽선, 짙은 받침, 크롬 모서리로 띄운다. 주인공의 실루엣과 헤드라인을 먼저 읽게 하고, 그 아래에는 작은 리본 띠나 보조 제목을 붙인다.
3. **크기가 다른 정보 네 층.** 큰 제목 → 보조 띠 → 소품이 있는 패널 → 가장자리 배지·게이지·작은 기호 순으로 시선을 움직인다. TOP 목록은 보여줄 항목이 있을 때 쓴다. 예를 들어 출근 포스터에는 알람·커피·지하철·회의 패널과 ‘졸림 MAX’가 어울린다.
4. **모서리까지 밀어 넣는 장식.** 왕관·월계수, 보석·다이아, 번개·폭죽, 메달·리본·체크 표시 같은 여러 종류를 섞는다. 간판과 장식은 겹쳐도 가장 큰 글자와 얼굴은 가리지 않는다. 여백을 채울 때 주제에 맞는 소품이나 아이콘을 우선한다.
5. **주제색에 금박과 네온을 얹는다.** 주제나 브랜드의 색을 바탕에 두고 금속 반사, 홀로그램, 강한 림라이트와 별빛을 더한다. “조금 화려하게”면 패널과 발광 효과를 줄이고, “킹받게/끝까지”면 중앙 위계를 유지하면서 가장자리까지 패널, 광선, 장식으로 채운다.

## 프롬프트와 확인

프롬프트는 **포맷·비율 → 주인공과 사건 → 배경 무대 → 정확한 한글 문구와 크기 → 패널·소품 → 금속 재질·빛·밀도** 순으로 작성한다. 한글 문장은 따옴표로 지정하고 가장 큰 문구는 짧게 유지한다. 작은 칸은 한두 단어, 아이콘, 체크 표시로 채운다. 도구가 긴 프롬프트를 잘 소화하지 못하면 주인공, 헤드라인, 패널, 색·재질, 가장자리 밀도만 남긴다.

실제 인물·브랜드·서비스에 관한 날짜, 출시 여부, 수치, 순위, 추천, 인증, 성능은 사용자가 준 정보나 확인된 사실에 근거한다. 근거가 없으면 ‘기대감 폭발’, ‘컴백 열기 MAX’처럼 상태나 분위기로 표현한다. 공식 발표처럼 보일 수 있는 가상 사건은 패러디임을 드러낸다.

생성 후 작은 크기에서도 주인공과 제목이 먼저 보이는지, 중요한 한글 문구가 정확한지, 장식이 모서리까지 채워졌는지 확인한다. 글자가 틀렸으면 문구를 줄이거나 해당 영역을 수정한다. 사용자가 준 문구를 그대로 써야 하는데 이미지 도구가 계속 틀리면 글자를 얹을 영역을 확보하고 편집 도구에서 정확한 문구를 넣는다. 수정 수단이 없으면 남은 오탈자를 알린다.
